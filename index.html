Rules used in this game

  • Each player has four tokens that start in their yard. Roll a 6 to bring one out onto your start cell.
  • Move clockwise around the board, then up your coloured lane. You need the exact number to land on the final home cell.
  • Land on an opponent's token to capture it. It goes back to its yard. Tokens on safe cells (start cells and stars) cannot be captured.
  • You get an extra turn when you roll a 6, capture a token, or bring a token home.
  • Three 6s in a row cost you the turn. If no token can move, the turn passes automatically.
  • The first player to bring all four tokens home wins.

About

Ludo Lane is a student-friendly web project built with plain HTML, CSS and JavaScript. Online rooms use Firebase Authentication and the Realtime Database. Offline and AI games run entirely in your browser and use the same rules engine.
